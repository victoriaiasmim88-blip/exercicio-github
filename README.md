# exercicio-github
# Sistema de Divulgação e Relacionamento com Clientes

Projeto desenvolvido como MVP (Produto Mínimo Viável) utilizando Metodologia Ágil (Kanban) para a disciplina do Prof. Josivan (Faculdade Grau).

## Aluna
- Iasmin

## Sobre o Projeto
Plataforma desenvolvida para otimizar a comunicação entre pequenos comerciantes e clientes, permitindo a gestão do catálogo de produtos, divulgação de novidades e campanhas promocionais.

## Funcionalidades Principais (MVP)
- **US01:** Cadastrar produtos no catálogo
- **US02:** Visualizar catálogo de produtos
- **US05/US06:** Criar e visualizar campanhas e promoções
- **US07:** Contacto direto com o estabelecimento.
